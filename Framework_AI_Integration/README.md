# Framework AI Integration

> **Status: candidate design — not verified and not implemented.**
> This document is a proposal for review. It does not describe a deployed
> capability, it authorises no public alert or physical action, and it records
> no verified result. Numeric figures are acceptance targets, not measurements.
> See [PROJECT_STATUS.md](../PROJECT_STATUS.md) for the claim policy and the document
> precedence order.

## Scope

Integration of AI frameworks (for example GENIEAI, OPEA, Haystack, or
GovStack) for document ingestion, retrieval, summarisation, and
conversational interfaces that support analyst review.

## Boundary

- Design material only. Model outputs are decision support, never an alert
  and never an action.
- Intended-purpose definition, dataset governance, evaluation, and
  human-oversight evidence are release prerequisites (see
  [Compliance and Ethics](../Compliance_and_Ethics.md)).
