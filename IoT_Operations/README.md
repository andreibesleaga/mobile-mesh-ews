# IoT Operations

> **Status: candidate design — not verified and not implemented.**
> This document is a proposal for review. It does not describe a deployed
> capability, it authorises no public alert or physical action, and it records
> no verified result. Numeric figures are acceptance targets, not measurements.
> See [PROJECT_STATUS.md](../PROJECT_STATUS.md) for the claim policy and the document
> precedence order.

## Scope

Lifecycle management for managed field devices and their connectivity —
enrolment, identity, telemetry, configuration, firmware update, and
decommissioning.

## Boundary

- Design material only. No device is enrolled, provisioned, or controlled
  by this repository.
- Device identity, update signing, and revocation are security release
  prerequisites (see [Security](../ARCHITECTURE/Security.md)).
