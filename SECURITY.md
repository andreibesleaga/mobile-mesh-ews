# Security Policy

## Scope

Mobile Mesh EWS is not an operational service. The current security scope is the public repository and its research artefacts. No external alerting, telemetry, or physical-control endpoint is operated by this project.

## Reporting a repository vulnerability

Do not post exploit details, credentials, personal data, or potentially harmful operational material in a public issue. Use GitHub's private vulnerability-reporting feature for this repository when it is available. If it is unavailable, open a minimal public issue asking the maintainer for a private reporting channel; include no exploit details. The maintainer must establish a monitored private channel before accepting operational contributions or deployments.

Please include the affected file or revision, a concise impact description, reproducible steps or a safe proof of concept, and any proposed remediation. Reports are handled on a best-effort basis; this document does not promise a response time or support window.

## Disclosure

Do not disclose details publicly until the maintainer and reporter agree that remediation or a documented risk decision is complete. For issues involving a future deployment, also follow the relevant operator's incident and regulatory procedures.
