# Remote Operations

> **Status: candidate design — not verified and not implemented.**
> This document is a proposal for review. It does not describe a deployed
> capability, it authorises no public alert or physical action, and it records
> no verified result. Numeric figures are acceptance targets, not measurements.
> See [PROJECT_STATUS.md](../PROJECT_STATUS.md) for the claim policy and the document
> precedence order.

## Scope

Integration with external systems and devices beyond the core mesh —
sensors, robots, and uncrewed aircraft — including legacy hardware.

## Boundary

- Design material only. It commands no vehicle, aircraft, or field device.
- Any physical operation requires an approved operational design domain,
  regulator approval, a tested safe state, and named human authority
  (see [RISKS.md](../RISKS.md) R-08).
